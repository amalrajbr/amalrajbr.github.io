Claude Code plugins

Built to build.

Three Claude Code plugins I wrote and keep in a private marketplace. They audit the work, run the review-and-fix loop, and keep a long run moving while I do something else.

  1. Code Review

    Audits the whole branch, not just the diff.

    Checks your code against an antipattern catalogue owned by your repository and mined from its own bug-fix history, then proves each candidate before reporting it: with a test, a browser check, or a live datastore query. Anything it could not verify is labelled as such.

    • Elixir / Phoenix
    • Django, DRF, Ninja
    • Test, browser and datastore checks

  2. Review Orchestration

    From issue to a passing review, round by round.

    Starts from a GitHub issue, a pull request, a plan file or your current branch. A triage pass extracts the acceptance criteria, then a persistent reviewer and developer pair work one unit at a time, writing a versioned review doc each round until every unit passes. It reports back on the issue or PR.

    • Issue, PR, plan or branch
    • Versioned review trail
    • Recovers a round if a teammate drops

  3. Monitor Loop

    Long runs that don't stall.

    Arms an hourly heartbeat inside your session for multi-hour agent runs. It notices a teammate that has gone quiet and nudges it, detects when the work is done, and carries on after a rate-limit pause for as long as the session stays open.

    • Hourly heartbeat
    • Stall detection
    • Survives rate-limit pauses
