Developer tooling

Built to build.

Three Claude Code plugins I wrote for my own workflow. They review the work, fix it, and keep a long run moving while I do something else.

  1. 01 Code Review

    Reviews the whole branch, not just the diff.

    Checks your code against the mistakes your own repository has already made, and verifies each finding before reporting it. You get a clear verdict, and anything it could not verify is labelled as such.

    • Elixir / Phoenix
    • Django
    • Learns from your bug history

  2. 02 Review Orchestration

    From issue to approved PR, round by round.

    A reviewer and a developer work as a persistent pair, starting from a GitHub issue, a pull request, a plan file or your current branch. They review, fix and re-review until every unit of work passes, leaving a written record of each round.

    • Issues and pull requests
    • Versioned review trail
    • Reports back on GitHub

  3. 03 Monitor Loop

    Long runs that don't stall.

    Keeps a multi-hour agent run moving. It notices when a teammate has gone quiet, nudges it, recognizes when the work is done, and rides out rate-limit pauses without losing progress.

    • Stall detection
    • Rate-limit safe
    • Hands off when done
